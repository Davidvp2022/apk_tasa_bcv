# Tasa BCV

Esto es un mini-proyecto que hice para practicar programacion con
Flutter en Android
## Informacion nada importante...

Pues no hay mucho que decir, es una aplicacion para ver
las diferentes tasas del dolar en Venezuela.

* Dolar BCV
* Euro BCV
* USDT Promedio

Es algo basica pero tiene su calculadora, la idea de la app nació porque
las aplicaciones de Google Play que hacen lo mismo tienen mucha publicidad
entonces en muchas ocasiones se necesita ver la tasa rapido y pues la 
publicidad no deja...
